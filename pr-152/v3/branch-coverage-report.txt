BRANCH + LINE COVERAGE — new/changed code of the session-close patch (issue #146)
================================================================================

Method
------
Rust branch coverage requires the nightly flag `-Zcoverage-options=branch`
(emits BRDA records; what `cargo llvm-cov --branch` produces). Toolchain:
nightly-2026-10-x86_64 (rustc 1.101.0-nightly, 32dba69d6) + llvm-tools-preview.

    rm -rf /tmp/ntarget && LLVM_PROFILE_FILE='/tmp/bcov/martty-%p-%9m.profraw' \
      RUSTFLAGS='-C instrument-coverage -Zcoverage-options=branch' \
      CARGO_TARGET_DIR=/tmp/ntarget cargo +nightly test --locked
    # 859 tests, all pass; profraws merged with llvm-profdata
    llvm-cov show <unit-test-bin> -instr-profile=martty.profdata \
      -sources <file> -show-branches=count > show-<name>.txt

A checker script then intersects `git diff origin/main -U0` added lines with
the show dumps: every added line must be executed (line coverage), and every
BRDA record on an added line must have BOTH the True and False sides hit at
least once (branch coverage). Branch records on the same (line,col) are
unioned — rustc emits a duplicate record per inline expansion, so a raw
listing double-counts sides.
